# Framecraft

AI-enhanced creative production workspace for music-to-video workflows.

## Product workflow

Create → Lock → Direct → Animate → Review → Export

## Initial scope

- Project and scene management
- Script and shot planning
- Character continuity references
- Audio alignment and caption preparation
- Camera moves, grading, grain, vignette, dissolves, and letterboxing
- Reviewable MP4 export pipeline

## Protection rule

Do not commit production credentials, model keys, proprietary prompts, private media, or unreleased customer material.
