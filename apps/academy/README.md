# Righteous Warrior Good Steward Academy

Educational platform for structured courses, lesson videos, publications, student access, and evidence-led stewardship study.

## Initial scope

- Public academy and publication catalog
- Student registration and secure lesson access
- Video lesson library and progress tracking
- Downloadable educational resources
- Clear educational-use and legal-information notices

## First vertical slice

A public landing page, course catalog, student sign-in placeholder, and one sample lesson pathway.
